# AnyGrasp D405 ROS Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a perception-only ROS Noetic package that runs the validated AnyGrasp SDK on the live D405 PointCloud2 stream and publishes camera-frame grasps for RViz.

**Architecture:** A pure-NumPy core module implements RGB, ROI, and rotation conversions; one ROS executable owns latest-frame scheduling, SDK inference, and publications. The launch file invokes the existing AnyGrasp Conda interpreter and includes no motion-control components.

**Tech Stack:** ROS Noetic, Python 3.9 Conda, NumPy, AnyGrasp SDK, graspnetAPI, sensor_msgs, geometry_msgs, visualization_msgs, unittest.

**Spec:** `docs/superpowers/specs/2026-08-28-anygrasp-d405-design.md`
